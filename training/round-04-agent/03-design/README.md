# B7-1 — 신규 설계

**PLAN_ONLY / NOT_STARTED / NOT_VERIFIED.** 미션에 적합한 화면·CLI/API·모듈 구조, 데이터·이벤트 흐름, 보안·오류·시험과 증빙 설계.

새 Round 개발 실행 및 검증 결과는 사용자 별도 승인 후에만 기록합니다.

## B7-1 — B1-1~B7-2 전 미션 필수 기획·설계·검증 프로세스

**2026-10-27 Owner 확정:** [공통 미션 프로세스 V1.0](https://github.com/MetaStudy999/codyssey-basic/blob/main/standards/ROUND-04-AGENT-MISSION-PROCESS-STANDARD.md)은 **B1-1~B7-2 15개 전 미션**에 반드시 적용하며 본 B7-1 프로젝트도 포함합니다. 공식 미션 PDF·평가·필수/선택 요건을 우선하고 다른 미션의 기능·PASS를 전이하지 않습니다.

**각 세부 단계 원스톱 절차:** 공식 자료·HEAD 확인 → 기획 프롬프트 **V0.1** → 위험/누락 ID별 검토 → 최종 **V1.0** 보완 → 입문자 수준의 한글(영어/약어)·비유·Mermaid·코드/명령 설명·예상 결과·오류·재현·자가평가 포함 설계 → GitHub 독립 검증(상대 링크/구문/승인/SHA/원본) → 단계별 PASS/FAIL/NOT_VERIFIED 증거 기록·인계. 오류는 같은 단계에서 수정·재검증합니다.

| 단계 | 별도 MD 파일로 설계할 항목 | 현재 |
|---|---|---|
| 03-1 | 공식 요구·범위·수용 기준 | NOT_STARTED |
| 03-2 | 정보·사용자/챗봇 흐름·인터페이스 | NOT_STARTED |
| 03-3 | 구성 파일·모듈·의존·배치 | NOT_STARTED |
| 03-4 | 요청·상태·이벤트/에이전트 제어 흐름 | NOT_STARTED |

**적용 판정:** 현재는 공통 프로세스의 정책·목차만 반영해 **PLAN_ONLY**. 미션별 8개 설계 문서 또는 실제 앱/LLM 기능은 개발하지 않았습니다. 03-1~03-8의 문서·링크는 각 세부 단계가 진행될 때 작성합니다. 04 신규 소스, 실습 실행·서비스/배포·병합·실제 평가에는 사용자 **별도 명시적 승인** 필요. 기존 Round·루트·증빙·비밀정보를 보존하고 `RUNTIME/LEARNER/CLEAR=NOT_VERIFIED` 유지.
