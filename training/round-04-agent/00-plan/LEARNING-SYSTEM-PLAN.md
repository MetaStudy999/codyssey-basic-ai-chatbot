학습 분야: **웹 기반 AI 챗봇 서비스 개발**. 해당 미션 공식 요구사항/평가 기준이 우선입니다.

## 학습 목표
용어·원리 이해 → 코드 실행 결과 예측 → 흐름 추적 → PRIMM 예측(Predict)·실행(Run)·조사(Investigate)·수정(Modify)·제작(Make) → 자기 설명·오류 해결·독립 응용.

## 16개 방법
M01 용어카드, M02 개념 관계도, M03 비유·4컷, M04 Why 질문, M05 비교, M06 실행 예측, M07 코드 추적, M08 Parsons 코드 조립, M09 빈칸, M10 수정 실험, M11 Debugging, M12 백지 구현, M13 자기 설명, M14 문제 전이, M15 간격 복습/혼합 문제, M16 AI 힌트·오답 분석.

**AI 튜터 H1~H4** 질문→개념→절차→해설, 실제 도움 수준 기록. **L1~L5** 코드 보며→도식만→무자료→백지 구현→새 문제 적용. 회상 복습 초기안 직후·1·3·7·14·30일. 동등 난이도 사전/사후 과제 및 오답 피드백.
