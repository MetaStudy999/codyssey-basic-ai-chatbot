# B7-1 4종 학습·발표 계획

2026-10-26 사용자 승인. **계획만 반영하며 실제 슬라이드·미션 개발·실행은 미시작**.

- 발표 16장: 미션 목표와 검증 결과를 전달합니다.
- 학습 45장: 개념·구조·실제 코드·시험·오류·재현·평가를 학습합니다.
- 기술 부록 15~25장: 구조·구현 선택·한계·문제 해결을 심화합니다.
- 핵심 복습 1~2장: 주요 개념과 평가 설명을 압축합니다.
- 공통 자료: 설명 이미지와 실제 검증 결과를 구분합니다.

학습 45장은 01~04 목표, 05~10 기초 개념, 11~16 설계, 17~24 코드, 25~30 주요 흐름, 31~34 예외·안전성, 35~38 실행·시험, 39~42 재현·문제해결, 43~45 복습·평가로 구성합니다. B7-1은 AI 챗봇 서비스 개발 프로젝트 특성을 반영하며, 공식 미션 평가 기준을 우선합니다.

한글명(English, 약어), 4컷 만화, 구조도, 실제 코드와 검증 자료를 연결합니다. L1 코드를 보며 설명, L2 도식 설명, L3 자료 없이 설명, L4 핵심 재현, L5 새로운 문제 적용을 평가합니다. 실제 결과 없이는 PASS나 숙달 완료를 선언하지 않습니다.

00 계획→01 공식 요구→02 분석→03 슬라이드 설계→04 신규 코드→05~07 검증·평가→08 PPTX/PDF 제작→09 인계. **신규 코드 구현은 별도 승인 전 실행 금지**.
