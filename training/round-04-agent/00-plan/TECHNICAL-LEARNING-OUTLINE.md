## 5. 한글·영어·공식 약어와 설명·재현 확인

**첫 표기:** 한글명(English Full Name, 공식 약어). 원래 약어가 없는 용어에는 새 약어를 만들지 않습니다.

| 한글명 | 영어 원명 | 공식·통용 약어 | 입문 설명 |
|---|---|---|---|
| **프롬프트** | Prompt | 없음 | AI 모델에 전달하는 질문·지시 |
| **거대 언어 모델** | Large Language Model | LLM | 언어를 처리하고 생성하는 모델 |
| **응용 프로그램 프로그래밍 인터페이스** | Application Programming Interface | API | 시스템 간 요청 인터페이스 |
| **맥락** | Context | 없음 | 응답에 고려되는 주변 대화·자료 |

**자기 설명:** 프롬프트(Prompt)는 모델에 질문·지시·맥락을 전달하는 입력입니다. 출력이 문장으로 그럴듯해도 중요한 사실은 별도로 확인해야 합니다.

**종이 재현 예상 단계**
1. 학습용 질문이 입력됐다고 가정.
2. 모델이 맥락을 참고해 답변을 생성하는 절차 생각.
3. 응답과 근거가 맞는지 별도 검토.

**흔한 오해:** 모델의 자신감이나 문장 자연스러움은 사실 검증의 증거가 아닙니다.

**학습 확인:** 핵심 용어를 직접 설명할 수 있나요? 입·처리·출력 순서를 자료 없이 다시 그릴 수 있나요? 실제 테스트 여부를 구별할 수 있나요?

**검증 구분:** 학습 설명·그림·예상 결과는 실제 새 코드·시험·학습자 숙달 결과가 아닙니다. **NOT_STARTED / NOT_VERIFIED**.
